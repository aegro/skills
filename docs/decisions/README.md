# Decisoes

Por que as regras do `CLAUDE.md` sao o que sao.

Existe para o `CLAUDE.md` poder ser so regra. Ele e carregado no contexto de toda
sessao que mexe em skill, entao cada linha dele disputa espaco com a skill que a
pessoa veio editar — ele paga o mesmo imposto que cobra. Isto aqui nao e
carregado por ninguem: custa zero ate alguem vir discutir uma regra.

Escreva um arquivo novo quando a regra for do tipo que alguem vai querer derrubar
sem saber o que ela evita. Uma pagina, no passado, com o episodio concreto —
data, numero, PR. E justamente o que nao pode entrar no corpo de uma skill.

| Decisao | Regra que ela sustenta |
|---|---|
| [0001](0001-sem-version-por-skill.md) | nao existe `version:` no frontmatter |
| [0002](0002-titulo-palavra-a-mais-nao-caixa.md) | o crivo cobra palavra a mais no titulo, nao caixa |
| [0003](0003-crivo-le-os-reference.md) | as regras de corpo valem para `reference/*.md` |
